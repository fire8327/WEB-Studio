# Аналитический отчёт: исследование 15 веб-студий и digital-агентств (Vue / Nuxt / White Label / субподряд / аутстафф)

**Цель исследования:** изучить позиционирование, структуру посадочных страниц, B2B-офферы для агентств-партнёров, визуальный стиль, интерактивные механики, паттерны доверия и подачу контактов у 15 профильных игроков рынка — чтобы выявить лучшие практики и слабые места конкурентов для создания конверсионного сайта White Label студии разработки на стеке **Vue / Nuxt**.

---

## Методология и прозрачность верификации данных

В отчёт включены **только проверяемые факты**, полученные двумя способами:
1. **Прямой технический инспекшн (HTTP GET / парсинг HTML, мета-тегов, заголовков H1–H3, форм, ссылок, шрифтов и CSS-палитры):** выполнен для доступных страниц `recifra.ru`, `sibdev.pro`, `miridea.ru` (+ `/partnership/`, `/calculator/`, `/brief/`), `firecode.ru` (+ `/outstaffing`), `nutnet.ru` (+ `/services/outstaff`), `redlab.dev` (+ `/services/vue-js/`), `rocketdev.pro` (+ `/services/outstaffing`, `/services/tekhnicheskaya-podderzhka-saita-24-7-sla`), `bigtree108.com` (+ `/partnerships`).
2. **Верифицированный веб-поиск (`search_web`) по индексированным страницам и профилям:** использован для всех 15 компаний, включая домены, которые при прямом запросе вернули антибот-заглушку (`tsunami.group`, `sborkaproject.ru/.com`, `nopreset.ru`, `redlab.dev/partners-program/`), ошибку сервера (`webdoka.ru` главная — HTTP 500) или таймаут (`coditive.com`, `horenko-production.com`, `intent-solutions.com`).

> [!NOTE]
> Для каждого из 15 агентств ниже явно указан статус прямой проверки и источники фактов. Неподтверждённые параметры отмечены как «не выявлено в открытом доступе».

## Детальный разбор первой пятёрки

### 1. Digital-агентство «Рецифра» (`recifra.ru`)
* **Верификация:** прямой парсинг главной страницы (HTTP 200, Tilda) + веб-поиск.
* **Позиционирование и ЦА:** узконишевый диджитал-подрядчик для госсектора, региональных организаций и институтов развития (Ханты-Мансийск / Югра, фонды «Мой Бизнес», медицина, энергетика).
* **Структура главной (прямые заголовки H1–H3):**
  * `H1`: «Цифровизация регионов» → `H2`: «ОЦИФРОВАЛИ ЮГРУ» → «РАЗРАБАТЫВАЕМ И СОПРОВОЖДАЕМ» (сегментация по типам заказчиков) → «Мы умеем работать с госсектором» (масштаб, особенности заключения сделок/торгов, быстрая оценка).
* **Визуал и типографика:** сайт собран на **Tilda**, шрифтовая связка `Russo One` (брутальный индустриальный акцент в заголовках) + `Manrope` / `Montserrat` для основного текста.
* **White Label / Vue / Nuxt:** публичного оффера для агентств нет, упор на 1С-Битрикс (Золотой партнёр в госсекторе).
* **Контакты:** прямые ссылки в Telegram (`t.me/avp86` — вероятно личный контакт руководителя/менеджера, и канал `t.me/digital_recifra`).
* **Что взять / чего избегать:** *Взять* — чёткое снятие страхов ниши прямо на уровне H3 («Знаем про особенности заключения сделки»). *Избегать* — сборки корпоративного сайта технологического продакшна на Tilda (снижает доверие к инженерной экспертизе).

### 2. Digital-агентство «Цунами» (`tsunami.group`)
* **Верификация:** при прямом GET-запросе сработал антибот-фильтр; данные собраны через `search_web` по индексированным страницам `tsunami.group` и профилям на Workspace / Рейтинге Рунета.
* **Позиционирование и ЦА:** агентство полного цикла из Иваново (на рынке с 2011 г.), работающее по всей РФ как с прямым бизнесом, так и по модели **White Label / аутстаффа** для других веб-студий и агентств.
* **Офферы и стек:** сильный технический стек под капотом — Frontend (`Vue`, `Nuxt.js`, `React`, `Next.js`, TypeScript), Backend (`PHP`, `Python`, `C#`, `NestJS`, `1С`), DevOps (`Docker`, `Kubernetes`, `CI/CD`, `Prometheus`, `Grafana`). Наличие в услугах разработки интерактивных калькуляторов.
* **B2B-формат:** агентство-партнёр ведёт коммуникацию с клиентом, а «Цунами» закрывает программирование, интеграции и техподдержку под брендом партнёра.
* **Слабое место:** антибот-челлендж на входе и размытие позиционирования между «делаем всё: от SMM и Tilda до C++ и Kubernetes».

### 3. Сборка Проект / Sborka Project (`sborkaproject.ru` / `sborkaproject.com`)
* **Верификация:** при прямом запросе `.com` редиректит на `.ru`, где срабатывает антибот-защита; данные подтверждены через `search_web` по страницам `sborkaproject.ru` и Workspace.
* **Позиционирование и ЦА:** бутиковый фронтенд- и креативный веб-продакшн из Санкт-Петербурга (с 2014 г.), **эталонный технический субподрядчик для топовых дизайн-студий и креативных агентств** (в партнёрах указаны `ONY`, `SETTERS`, `SLAVA`, `redkeds`, `Sulliwan Studio`).
* **B2B-УТП:**
  * Специализация на сложной анимации и интерфейсах (`Vue.js`, `Nuxt.js`, `Next.js`, `React`, `GSAP`, `WebGL`, `Three.js`, `PixiJS`) + Headless CMS (`Strapi`, `Kirby CMS`).
  * Готовность **подключаться на этапе пресейла**, усиливая тендерную/коммерческую заявку агентства-партнёра.
* **Блоки доверия:** мощнейший социальный пруф — награды **Awwwards (Honorable Mention)**, **CSS Design Awards (WOTD / Special Kudos)**, Tagline Awards, Рейтинг Рунета + бренды уровня Яндекс, VK, Сбер, Авито, МТС, Самокат, X5 Group.
* **Контакты:** акцент на скорости коммуникации — тезис «Мы всегда на связи в Телеграме», email `hello@sborkaproject.com`, физический адрес в СПб.
* **Что взять:** идею **поддержки на этапе пресейла** (для дизайн-студий это критически важно — помочь оценить смету и сроки ещё до продажи клиенту) и разделение портфолио с указанием наград.

### 4. Sibdev (`sibdev.pro`)

* **Позиционирование и ЦА:** крупная региональная студия веб- и мобильной разработки (офисы в Красноярске и Ульяновске, с 2015 г., 60+ штатных специалистов). Позиционируется и как заказной продакшн, и как **аутстафф/субподрядчик**.

  * Главная: `H1` «Разрабатываем сайты и приложения» → «Варианты сотрудничества» → «Портфолио» → «Технологии» → «Клиенты» → «С нами комфортно».
  * **Мощная SEO-сетка посадочных страниц** под каждый стек и нишу: `/outstaffing`, `/outstaffing-frontend`, `/outstaffing-vue`, `/outstaffing-react`, `/outstaffing-python`, `/online-calculators`, `/chatbot-telegram` и нишевые страницы (`/food-delivery-service`, `/carservice-website` и т.д.).

### 5. Веб-дока / WebDoka (`webdoka.ru`)
* **Верификация:** главная страница при прямом запросе вернула `HTTP 500 Internal Server Error`; детальные данные по тарифам, кейсам и White Label подтверждены через `search_web` по страницам сайта.
* **Позиционирование и ЦА:** петербургский продакшн полного цикла с 2005 года (>500 проектов). Работает как с конечными заказчиками, так и с агентствами на **аутстаффинге и White Label**.
* **Офферы и прозрачность цен:**
  * Чёткая сетка форматов: разовые задачи (от 3 000 ₽/ч), абонементная поддержка (от 15 000 ₽/мес за 7,5 часов), **выделенный разработчик / аутстаффинг от 2 000 ₽/ч** (при объёме от 80 часов/мес).
  * Аудит сайтов с фиксированным порогом (от 10 000 ₽).
  * Стек: 1С-Битрикс, Laravel, Symfony, Yii2, Node.js, Next.js, Vue/React.
* **Доверие и SLA:** официальное подписание **NDA** с каждым партнёром, SLA-поддержка 24/7, закреплённый персональный менеджер, подготовка КП по брифу в течение **1 рабочего дня**.
* **Слабое место:** техническая нестабильность собственного ресурса (500 ошибка на главной на момент проверки — фатальный антипаттерн для компании, продающей SLA 24/7 и техподдержку!).

### 6. Miridea (`miridea.ru`) — лидер по B2B-упаковке и конверсионным инструментам
* **Верификация:** прямой парсинг главной, `/partnership/`, `/calculator/` и `/brief/` (HTTP 200).
* **Что делает Miridea выдающейся (эталон структуры для партнёров):**

  * **Идеальные B2B-триггеры доверия (H3 на странице партнёрства):**
    1. *«Ваш клиент остается вашим»* (прямое снятие главного страха агентств — увода клиента);
    2. *«NDA и White Label»*;
    3. *«Ваша маржа защищена»*;
    4. *«Смета и сроки — до старта»*;
    5. *«Гарантия на работы»*;
    6. *«Ничего не держим в заложниках»* (передача кода, доступов, git).
  * **Сегментация ЦА партнёров:** студии с потоком задач, дизайн-студии без разработки, фрилансеры с крупными проектами, SEO/контекст/таргет-агентства.
  * **Интерактивный калькулятор (`/calculator/`):** стартовые пресеты («Лендинг ~78 000 ₽», «Корпоративный сайт ~194 000 ₽», «Интернет-магазин ~371 000 ₽», «Собрать с нуля 0 ₽») + модульные чипсы с ценой и тултипом `?` («Дизайн +45 000 ₽?», «UI-кит +10 000 ₽?», «Анимация при прокрутке +12 000 ₽?»).
  * **6-шаговый интерактивный бриф (`/brief/`):** разделён на логические табы `01 О компании` → `02 Задачи проекта` → `03 Дизайн и стиль` → `04 Структура и функции` → `05 Контент и технологии` → `06 Бюджет и контакты`.
  * **Микро-UX в форме заявки:** поле контакта с плейсхолдером `"+7 … или @username"` (принимает сразу и телефон, и Telegram-ник!), плюс radio-переключатель модели работы (`offer`) и поле под сайт/компанию.
* **Визуальная палитра:** светлый интерфейс (`#fff`, `#eef1f6`, `#e4e8f0`) с яркими акцентами `#f93c3c` (красный CTA), `#3f55c3` (индиго), `#a068f8` (фиолетовый).
* **Слабое место:** устаревший стек в ядре (нет акцента на Vue/Nuxt/SSR), ориентир на малый/средний бизнес и классические CMS.

### 7. Firecode (`firecode.ru`) — эталон тёмного тех-дизайна, прозрачных ставок и калькуляторов
* **Верификация:** прямой парсинг `/` и `/outstaffing` (HTTP 200, обнаружен Nuxt/Vue) + веб-поиск.
* **Визуал и технологии:** **сайт использует Nuxt/Vue**. Тёмная премиальная цветовая схема: глубокий графитовый фон (`#0b0d12`, `#1b1c26`, `#22232e`) + энергичный малиново-алый акцент (`#ed1746`, `#9a1737`, `#8b1231`) и белый текст (`#ffffff`).
* **Сильные UI/UX-решения:**
  * На главной в первом экране — чёткий выбор 4 форматов (`Аутстаффинг`, `Выделенная команда`, `Проект под ключ`, `Внедрение ИИ`) и **кликабельные карточки ролей прямо с ценой «от … ₽/ч» и ссылкой на стек** (`Backend · Frontend · Mobile · Fullstack — от 1 500 ₽/ч ↗`).
  * **Интерактивные виджеты на `/outstaffing`:** прямо в карточке каждого направления можно выбрать стек (например, `React / Vue / Angular`), грейд (`Middle+` / `Senior`) и количество часов (`input number`), мгновенно получая ориентир бюджета!
  * **Калькулятор сравнения «Аутстафф vs Штат»:** учитывает налоги (с IT-льготами и без), затраты на найм, технику, бенефиты, отпуска и больничные — мощнейший аргумент для финансового директора/тимлида.
  * **Жёсткие B2B-гарантии и доверие:** только Middle+ и Senior в штате по ТК РФ (без джунов и фриланса), тех. интервью с кандидатом до договора, подбор за 48 часов (1–3 дня), **почасовая постоплата**, бесплатная замена специалиста по SLA за 1–3 дня, бейджи **Минцифры России** и **ISO 9001**.
* **Слабое место:** фокус исключительно на аутстаффинге отдельных голов (не раскрыт сценарий White Label «под ключ» для дизайн-агентств, нет дизайн-портфолио промо-уровня).

## Слабые места конкурентов и как нам отстроиться (Blue Ocean)

1. **Массовое «всё для всех» вместо глубокой ниши:** 11 из 15 изученных компаний продают одновременно Битрикс, WordPress, Tilda, SEO, контекст и C++. Для дизайн-студии или продуктового агентства это сигнал «конвейера». **Наше преимущество:** узкая инженерная специализация **Vue 3 / Nuxt 3 + современный фронтенд (SSR, Core Web Vitals 95+, GSAP/анимации)** по модели **Coditive / Sborka Project** на русскоязычном и международном рынке.
2. **Либо красивый креатив без прозрачности (Sborka), либо сухая B2B-таблица без визуала (Sibdev, WebDoka):** у первых нет калькуляторов/ставок и сайт закрыт антиботом, у вторых — типовые светлые шаблоны на WordPress/Tilda. **Наше преимущество:** объединить **визуальную культуру премиального продакшна** (тёмная или контрастная тема уровня Firecode/Awwwards с микро-анимациями на Vue/GSAP) с **B2B-прозрачностью** (калькулятор, SLA, NDA-манифест).
3. **Технические фейлы на собственных сайтах:** HTTP 500 на главной (`webdoka.ru`), сайт веб-разработчика на Tilda (`recifra.ru`), агрессивные антибот-заглушки, мешающие открывать сайт по ссылке в Telegram (`tsunami.group`, `sborkaproject.ru`, `nopreset.ru`), таймауты (`coditive.com`, `horenko-production.com`, `intent-solutions.com`). **Наше преимущество:** **Nuxt 3 SSR/SSG** с мгновенным TTFB, идеальным OpenGraph-превью для мессенджеров и 95–100 баллами PageSpeed — сам наш сайт должен быть главным кейсом нашей Nuxt-экспертизы!
4. **Нехватка сценария «Анонимные/NDA-кейсы»:** многие агентства стесняются показывать White Label проекты, потому что не могут светить бренд. **Решение:** сделать в портфолио отдельный визуальный паттерн **«NDA / White Label Case»** (показываем обезличенную архитектуру, скринкаст/интерактивный макет без логотипа клиента, стек, цифры производительности и отзыв партнёра).
5. **Игнорирование пресейл-боли дизайн-студий:** большинство предлагают аутстафф «почасово после договора». Лишь единицы (Sborka Project, Miridea) акцентируют **бесплатную оценку по Figma/ТЗ за 24 часа для защиты сметы перед клиентом агентства**. Это мощный лид-магнит для первого касания.
